NetworkGuardian 便携版
====================

运行与更新
----------
Windows 10 2004（build 19041）及以上，x64。NetworkGuardian.exe 是原生 AOT 单文件，
提权助手及种子模型内置，目标电脑无需安装 .NET、Windows App SDK 或开发工具。
版本以 EXE 属性为准；0.14.0 验收大小约 13.12 MiB。

双击后可能最小化到托盘；从任务栏右下角托盘打开窗口。关闭窗口默认只隐藏，
更新前应从托盘退出旧版，再运行新版。数据保存在当前用户目录，更新 EXE 会沿用。

先在“网卡管理”核对设备，在“网络凭据”添加网络，在“无线网络”扫描与连接，
在“自动管理”核对恢复、探测、认证和学习设置。设置会防抖自动保存，
“保存并应用”用于立即确认保存。写操作需要确认，侧栏切换和只读操作不用确认。

网络与设备
----------
质量由丢包、失败、延迟、抖动等实际证据评估；首次运行需要积累采样。
SSID 指定网卡适用于普通及校园 Wi-Fi，优先于评分。保持禁用优先于自动启用，
即使暂停自动恢复也继续保持禁用；不需要该规则时，应在软件内取消。
设备启用、禁用、重启或管理员命令可能请求 UAC，主程序通常以普通用户运行。

Npcap 是可选的出口验证依赖，未安装时降级运行。Windows 11 读取无线标识可能
需要定位服务及桌面应用位置权限。链路连接、取得 IP 与外网可用应分别判断。
VPN/TUN、代理、ICMP 过滤和认证门户可能影响探测结果，请查看质量报告和日志。

AI / MCP 与训练
---------------
在“自动管理 → AI 工具接入 / MCP”开启，默认关闭，默认地址：
http://127.0.0.1:18765/mcp
端口可改，始终只监听 IPv4 回环，无鉴权。MCP 写工具直接执行，不弹界面确认；
Windows UAC 仍适用。默认凭据查询隐藏密码，显式 includeSecrets 可读取可解密密码。

项目 skills/networkguardian 可导入 Agent，支持查询、诊断及教师标注、后台训练、
验证部署和回滚。训练每 5 epochs 保存进度；Agent 断线后继续，软件重启后可续训。
验证误差不是实际联网准确率；模型不能绕过 SSID 指定和保持禁用。

数据与备份
----------
默认目录：%LOCALAPPDATA%\NetworkGuardian\
config.json / config.backup.json：设置和设备规则。
wifi-networks.json：凭据库，密码由当前 Windows 用户 DPAPI 保护。
network-history.json：质量、偏好和权威模型状态。
network-brain.json：权重副本，不要只替换此文件恢复模型。
network-survey.json：用户回答与现场上下文。
distillation\：教师标签、训练检查点和回滚模型，按需创建。
Logs\ / helper\：日志与临时助手通信。

备份或恢复前退出程序，复制完整数据目录。DPAPI 密文通常无法跨用户或电脑解密。
配置、日志、导出和自定义认证 XML 可能包含用户填写的敏感信息，共享前按需检查。
程序日志不记录 MCP 工具参数和外部认证命令参数。
