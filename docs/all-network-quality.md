# 全接口质量评分与训练数据

## 开发检查点

- 统一接口/网络身份，兼容旧 Wi-Fi 历史；有线、无线、隧道、虚拟及其他接口均使用实测质量规则。
- 对未连接、回环、无可用探测地址、无公网路由的接口明确说明适用范围；不把虚拟局域网或回环当公网断网，不伪造实测分数。
- 持续采样、报告、接口状态、问答上下文及蒸馏观测样本共用匹配规则，防止网络变化后串用历史。
- 公网端点连接失败不是物理丢包；公网 ICMP 过滤不直接扣成断网；无无线信号的网络使用中性信号特征。
- 保留现有 8 维模型及训练/部署门槛，训练样本增加网络类型和身份的可追溯元数据，不虚构主观标签。
- 完成单元、原生探测及隔离 EXE 验证后，备份桌面旧 EXE、请求原进程退出、等待 WFP 规则释放、同名替换，再启动并验证真实采样及报告。
