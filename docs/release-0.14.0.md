# 0.14.0 交付记录

## 模型蒸馏与 Agent Skill

- MCP 增加 `training_status`、`training_examples`、`model_distill`，总计 41 个工具。继续仅监听 IPv4 127.0.0.1，沿用开关和端口设置。
- 独立教师标签入口：样例由服务器生成，区分合成场景和近期聚合实测；Agent 给效用目标、置信度和理由，不改写真实网络探测或用户答题。
- 后台训练与 HTTP 连接独立，每 5 epochs 原子保存任务。断线不停止，软件重启后 start 续训；requestId 防重复创建，相同标签可重试，训练开始后冻结数据。
- 留出教师误差和独立专家策略检查通过才部署，当前模型变化拒绝覆盖；保存回滚权重，回滚也比较版本，避免丢失后续个人学习。保持禁用、SSID 指定和决策保护约束不变。
- 每任务最多 512 样例、1000 epochs，同时运行一项、最多 64 任务；可清理已被后续部署替代的旧任务，保留当前部署。
- `skills/networkguardian/` 可整体导入 Agent；附训练协议、网络诊断方法和无需第三方依赖的 Python MCP 客户端。默认长期任务一小时、最多 12 批次，连续两批无改善停止，不能绕过 Agent 平台配额和会话期限。
- Skill ZIP 通过 `tools/package-agent-skill.ps1` 重建。未内置模型服务密钥，Agent 自身可担任教师；没有擅自调用外部付费模型或改写用户当前权重。

## 验证

389 项测试通过，新增 8 项训练持久化、后台执行、冻结数据、暂停/重启续训、部署回滚、陈旧基线拒绝、损坏备份恢复、旧部署清理测试。

最终 Native AOT EXE 通过官方 Python MCP 客户端 76 次隔离调用，含 160 条确定性测试标签、300 epochs 后台训练、留出评估、部署和回滚；回滚后当前模型哈希与训练前完全一致。Skill 的标准库客户端也连接同一实际服务器验证。测试教师为确定性网络专家规则，验证接口和训练流水线，不代表已经通过大模型训练出更好的真实选网策略。

未为验证禁用、重启或切换用户真实网卡。测试进程使用独立配置及数据目录，不修改用户的开机启动项或现有模型。隔离状态和日志位于本地 `artifacts/qa-mcp-0.14.0-final/`，不提交机器网络快照。

Skill 校验通过，ZIP 检查为 4 个所需文件，无缓存和密钥。13 页中文说明书用现有 XeLaTeX 编译，无排版警告并检查页面；内置编译器报告无法找到标准目录，未把该失败当成成功编译。
