# NetworkGuardian 0.11.0：选择题与本地网络模型

主页提供 60 道动态选择题，覆盖校园归属、SSID/网卡偏好、稳定性体验、质量取舍、流量成本、主备角色、恢复偏好与时段习惯。
题干填入当前连接的 SSID 和网卡；离线时只出现无需当前连接的通用问题。
选项按 A/B/C 展示，网卡选项随本机设备生成。回答后自动换题，跳过不进入训练集；避免连续重复同一道题。
答题不会直接连接、断开网络或修改硬绑定。

## 数据与信任

每条回答保存出题时和回答时两份状态快照：时间及偏移、接口/SSID、频段、信号、按接口联网结果、质量采样、可见 SSID、绑定规则和自动恢复状态。
不会收集密码、网页、应用内容或通信载荷。
回答保存为软标签。网络状态变化会降权；稳定性感受与近期探测明显冲突时降低权重，中间质量区间不武断否定用户感受。
探测本身不能证明“学校提供”或“按流量收费”，这些回答只保留为带权线索，不自动更改校园网配置或成本规则。
选择偏好进入已有的成对偏好模型；有足够测量的质量取舍数据用于小神经网络增量更新。其余语义标签进入软知识与答题数据集，不强行当作质量真值。
没有吞吐测量时，不用 Wi-Fi 信号强度冒充带宽来训练速度偏好。

## 内置小模型

模型是 8-8-1 的小型全连接网络：输入为质量、失败率、延迟、抖动、信号、证据充分度、联网验证及软偏好，隐藏层 tanh，输出 sigmoid 网络效用。
它是数值网络效用模型，不是能够理解任意语言或完整掌握网络协议的通用大模型。
系统继续由硬约束、探测、质量策略与模型协作管理网络，模型最多有限调整候选评分，不能绕过指定网卡、实测可用性或质量门槛。

本版本真实完成了以下训练流程：

1. 6,000 组合成专家规则场景预训练，240,000 次参数更新；独立 1,500 组合成规则验证集 MAE 约 0.0139。
2. 通过用户授权的接口调用声明为 `deepseek-v4-flash` 的教师模型，仅发送 160 组匿名数值合成场景，没有发送本机网络或用户历史。
3. 128 组用于蒸馏，32 组独立验证，额外 57,600 次更新；目标混合 75% 教师标签与 25% 专家规则锚定。
4. 对上述 32 组保留教师标签的 MAE 约 0.1212。这是合成效用拟合误差，不是真实网络准确率或操作成功率。

教师标签、特征顺序与训练/验证划分见 `tools/NetworkGuardian.Training/teacher-distillation.json`。
本地复现训练，不需要 API key：

```powershell
dotnet run --project tools/NetworkGuardian.Training -c Release -- src/NetworkGuardian.Core/Models/network-brain.seed.json tools/NetworkGuardian.Training/teacher-distillation.json
```

运行期不依赖教师接口。API key 和接口凭据没有写入源码、训练集或 EXE。
内置权重在首次启动时释放到本机数据目录 `network-brain.json`，个性化状态同时保存于 `network-history.json`。
答题集单独保存在 `network-survey.json`，只有回答、删除、重置时写入，避免每次网络采样重复重写大型训练集。
历史文件保存模型状态，独立模型文件是可查看的权重副本；写入使用临时文件、原子替换和备份。答题集与权重版本不一致时，从保留数据重训恢复。
没有硬件实测支撑的回答不应让模型自信起来；个人更新使用小学习率并保留专家锚定。

## 任务置信度

任务卡显示本轮计划及最近六条下发记录，包括置信度和证据说明。
置信度是基于样本数、新鲜度、扫描与外网验证的启发式“依据可信度评分”，没有声称经过统计校准，不能解释为操作成功概率。
用户回答数量不直接提高任务置信度。下发记录也不等于任务已成功，成功仍以实际返回与后续探测为准。

## 本地管理

支持查看最近五条答题记录、删除并从保留数据重训、导出 `network-survey-export.json`、重置答题集与模型。
最多保留 1,000 条回答，软标签表有上限；重训基于当前保留的数据。
旧版本的网络质量历史、SSID 绑定和偏好数据保持兼容。
答题数据包含本机 SSID/网卡信息，仅保存在本地，教师蒸馏没有使用这些信息。
