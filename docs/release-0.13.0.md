# 0.13.0 交付记录

## 功能

- 本机 Streamable HTTP MCP，38 个工具，仅绑定 IPv4 `127.0.0.1`，无鉴权；默认关闭，固定默认端口 18765，设置中可开启和改端口。
- 配置、凭据、网卡、无线连接、校园网、认证命令、问答学习与调试工具接入现有后端；写操作直接执行，Windows UAC 仍适用。
- 自身端口变更或停用仍能返回当次结果；端口占用不会改绑其他地址或静默选端口。
- 默认凭据查询不返回密码、加密密文或可能内嵌密钥的自定义 XML；显式请求 secrets 时可查询。
- 从零撰写 12 页中文 LaTeX 使用说明，附 38 工具索引、接入示例和故障排查；源码、PDF 和重建脚本随 Git 提交。

## 验证

381 项自动测试通过。官方 Python MCP 客户端对最终 Native AOT 成品的 53 次隔离调用通过，包括真实扫描和探测、配置校验/持久化、模型回答、凭据维护、无副作用配置命令、热切换端口、新端口上的自停用。
没有为了验证而禁用、重启或切换用户当前使用的物理网卡；硬件控制和认证仍以实际 Windows/网络返回为准。

PDF 用现有 XeLaTeX 编译，字体嵌入，版面抽检通过；无 Overfull/Underfull、缺字或未解析引用警告。12 页全部含内容，38 个工具名均在 PDF 中验证。内置预览编译器无法定位标准目录，使用本机 TeX Live 完成实际 PDF 交付。
