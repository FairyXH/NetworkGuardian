# 0.12.1：网络质量评价报告

运行概览顶部提供自动刷新的自然语言报告，包括外网是否可用、当前出口、每块无线网卡的实测评价、依据充分度与操作建议。
报告展示设备名称、连接 SSID、评级、丢包/外网连接失败、延迟与抖动，并解释这些数据可能对使用体验造成的影响。

当前 8-8-1 数值神经网络用于有限调整候选网络效用评分，并从有实测支撑的偏好回答中继续训练；它不能自由生成自然语言，也不能证明网卡硬件损坏。
报告文字使用实测数据与可测试的解释规则生成，不调用在线大模型，不发送本机网络数据。
模型个人更新次数用于说明学习状态，不能理解为选网准确率、任务置信度或网络质量分数。

只有与当前接口、SSID、频段一致，且五分钟以内、至少五组采样，并已有本地链路或外网连接失败测量的记录，才给出质量评级。
没有足够证据、记录过时、采样关闭、未连接时明确说明限制；不拿其他网络的历史成绩评价当前连接。
公网 ICMP 无回应但 TCP 正常时，解释为可能不响应 ping，不据此判断断网；本地丢包只提示链路风险，不直接断言 USB 网卡损坏。
一次外网探测失败但稳定性判断仍在线时，明确表示正在复查。
有线网络目前仅描述链路和联网情况，不伪造持续质量评分；没有吞吐量测量，不推断下载带宽。

报告仅解释现状，不自动执行建议；连接、切换、绑定和禁用继续遵循已有规则与确认流程。

353 项自动测试通过，新增报告测试覆盖良好连接、本地丢包、ICMP 过滤、样本不足、过期/未来时间、未知测量、旧 SSID/频段、关闭采样、有线连接与备用网络不能代表当前出口已恢复的表述边界。
